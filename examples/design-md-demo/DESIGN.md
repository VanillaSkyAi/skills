# Perch design language

Perch watches cron jobs and scheduled tasks for indie hackers. The brand is
nocturnal: a chartreuse perch-light accent (`#C7F464`) and coral (`#FF6B6B`)
reserved for alerts, over whatever night the gradient conjures. Headings are set in
Playfair Display — an owl in a tuxedo, not a dashboard in a hoodie.
